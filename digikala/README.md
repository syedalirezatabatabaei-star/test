# دیجی‌کالا — استخراج محصولات و قیمت به Excel

ورک‌فلو مستقل n8n برای جست‌وجوی محصولات عمومی دیجی‌کالا و ساخت فایل XLSX.

## منابع بررسی‌شده
- [amupouya/digikala-mcp](https://github.com/amupouya/digikala-mcp): پیاده‌سازی جدید با جست‌وجو، جزئیات محصول و فروشندگان؛ endpoint جست‌وجوی عمومی را مستند کرده است.
- [sepehr071/digikala-mcp](https://github.com/sepehr071/digikala-mcp): جست‌وجو، فیلترها، قیمت، فروشنده و استخراج کارت محصول.
- [rezashahnazar/digikala-mcp-server](https://github.com/rezashahnazar/digikala-mcp-server): نمونه جست‌وجو با فیلترهای قیمت، برند، دسته و تخفیف.

## Endpoint
`GET https://api.digikala.com/discovery/api/v2/search`
پارامترهای مورد استفاده در این ورک‌فلو: `q`, `page`, `sort`, `price[min]`, `price[max]`, `categories[]`, `has_selling_stock`. قیمت‌های ورودی API ریال‌اند؛ ورودی کاربر تومان است و در درخواست در 10 ضرب می‌شود.

## Webhook
`POST /webhook/digikala-products-excel`
Authentication روی `None` است تا با تنظیم فعلی n8n شما سازگار باشد. URL وبهوک را عمومی منتشر نکنید.

نمونه Body:
```json
{
  "query": "گوشی سامسونگ",
  "limit": 20,
  "page": 1,
  "sort": "relevance",
  "min_price": 5000000,
  "max_price": 30000000
}
```

فیلدهای ورودی:
- `query`: عبارت جست‌وجو (حداقل 2 کاراکتر، فارسی یا انگلیسی)
- `limit`: تعداد خروجی از همین صفحه، حداکثر 20
- `page`: صفحه 1 تا 100
- `sort`: `relevance`, `cheapest`, `most_expensive`, `best_selling`, `most_viewed`, `newest`, `fastest_delivery`, `buyers_pick`
- `min_price`, `max_price`: تومان
- `category_id`: شناسه عددی دسته‌بندی
- `in_stock_only`: پیش‌فرض true؛ برای نمایش همه وضعیت‌ها false بفرستید.

## ستون‌های Excel
شناسه و نام محصول، قیمت و قیمت قبل از تخفیف به تومان، درصد تخفیف، موجودی، فروشنده و امتیاز فروشنده، برند، دسته‌بندی، شناسه واریانت، رنگ، گارانتی، وضعیت شگفت‌انگیز و دیجی‌پلاس، لینک محصول و زمان دریافت.

## محدودیت‌ها
- این endpoint عمومی وب‌سایت است، نه API عمومی تضمین‌شده برای استفاده تجاری؛ ممکن است تغییر کند.
- هر درخواست یک صفحه نتایج را می‌خواند؛ حداکثر 20 محصول از همان صفحه به Excel می‌رود. برای صفحه بعد `page` را تغییر دهید.
- فیلتر شهر یا مختصات در این جست‌وجو تعریف نشده؛ نتایج بازار دیجی‌کالا هستند، نه صرفاً اصفهان.
- در صورت دریافت 403 یا 429، درخواست را متوقف و بعداً با فاصله بیشتر تست کنید؛ CAPTCHA یا محدودیت دسترسی دور زده نمی‌شود.
- خروجی و endpoint زنده در این commit روی n8n شما اجرا نشده‌اند؛ ساختار پاسخ ممکن است تغییر کرده باشد. اولین اجرای واقعی باید اعتبارسنجی شود.
- قیمت‌ها از ریال به تومان تبدیل می‌شوند. اطلاعات فروشنده/رنگ/گارانتی بسته به محصول ممکن است خالی باشد.
