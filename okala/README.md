# اُکالا — استخراج محصولات و قیمت

این پوشه یک ورک‌فلو مستقل n8n برای دریافت محصولات دسته‌بندی‌های اُکالا و ساخت Excel دارد.

## فایل‌ها
- `workflows/okala-products-excel.json`: فایل قابل Import در n8n
- این راهنما: ورودی‌ها، نصب و محدودیت‌ها

## روش کار
1. Webhook درخواست POST را دریافت می‌کند.
2. ورودی و مختصات کنترل می‌شود.
3. در صورت ندادن `category_slug`، دسته‌های نزدیک به عبارت فارسی از درخت دسته‌بندی اُکالا پیدا می‌شوند.
4. حداکثر دو دسته هم‌امتیاز برای دریافت محصولات استفاده می‌شود.
5. محصولات بر اساس شناسه فروشگاه و محصول یکتا می‌شوند.
6. قیمت ریالی API به تومان تبدیل و تخفیف/موجودی استاندارد می‌شود.
7. فایل `okala-products.xlsx` به درخواست‌کننده برگردانده می‌شود.

## ورودی Webhook
`POST /webhook/okala-products-excel`

در تنظیم فعلی، Authentication نود Webhook روی `None` است. چون احراز هویت غیرفعال است، URL وبهوک را عمومی منتشر نکنید؛ هر کسی که URL را داشته باشد می‌تواند درخواست بفرستد.

نمونه Body:
```json
{
  "query": "شیر",
  "lat": 32.6546,
  "lon": 51.6680,
  "limit": 50
}
```

یا slug دقیق دسته:
```json
{
  "category_slug": "dairy-products",
  "query": "لبنیات",
  "lat": 32.6546,
  "lon": 51.6680,
  "limit": 100
}
```

اگر مختصات ارسال نشود، مرکز شهر اصفهان (lat=32.6546, lon=51.6680) به‌عنوان پیش‌فرض استفاده می‌شود. برای محله یا فروشگاه مشخص، مختصات دقیق همان محدوده را ارسال کنید. مختصات باید متعلق به محدوده سرویس‌دهی اُکالا باشد. برای ایران، lat معمولاً 25..40 و lon معمولاً 44..64 است. شهر/آدرس کاربر به‌صورت خودکار حدس زده نمی‌شود؛ مختصات را از مرحله geocoding معتبر به ورک‌فلو بدهید.

## Import و راه‌اندازی
1. فایل JSON را در n8n از مسیر Workflows → Import from File وارد کنید.
2. در نود **Okala Products Webhook** مقدار Authentication را روی `None` قرار دهید (مطابق تنظیم فعلی شما). برای استفاده عمومی، احراز هویت را فعال کنید.
3. ورک‌فلو را ذخیره و فعال کنید.
4. با درخواست POST به آدرس `https://YOUR-N8N-DOMAIN/webhook/okala-products-excel` تست کنید.

## محدودیت‌های مهم
- این یک اتصال مستقیم HTTP به endpointهای غیررسمی و داخلی وب‌سایت است؛ API رسمی عمومی اُکالا نیست و ممکن است تغییر کند.
- این نسخه جستجوی متنی داخلی حساب کاربری را پیاده‌سازی نمی‌کند. جستجو با مهمان از روی نام دسته‌بندی انجام می‌شود؛ بنابراین عبارت‌هایی مانند نام برند یا مدل محصول ممکن است دسته مناسبی پیدا نکنند. برای نتیجه دقیق، `category_slug` ارسال کنید.
- endpoint محصولات نزدیک ممکن است برای هر فروشگاه تعداد محدودی محصول (در MCP upstream حداکثر ۱۲ محصول در هر فروشگاه) برگرداند؛ این نسخه تضمین‌کننده استخراج کل کاتالوگ یا همه صفحات نیست.
- اگر اُکالا پاسخ CAPTCHA/Challenge، 403 یا 429 بدهد، اجرا را متوقف کنید و بعداً با نرخ کمتر تکرار کنید. این workflow CAPTCHA را حل یا محدودیت دسترسی را دور نمی‌زند.
- این workflow در این commit به API زنده اُکالا یا n8n شما متصل و اجرا نشده است. قبل از استفاده عملی باید یک اجرای واقعی با مختصات تحت پوشش و خروجی Excel اعتبارسنجی شود.
- قیمت‌های خروجی تومان هستند؛ `price_toman` قیمت قبل از تخفیف (در صورت وجود) و `final_price_toman` قیمت پرداختی است.
